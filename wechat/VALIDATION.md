# 原型验证记录 · 2026-10-17

环境：macOS、Ruby 4.0.7、Node 26.10.0、Wenyan CLI 2.0.12、Chrome 155。
Browser 插件未提供，使用现有 Playwright CLI 检查。

## 当前出版规则

预览保留标题；默认复制、HTML 导出及 HTML 片段只含摘要与原文正文。
“仅复制正文”省略摘要。作者和具体日期不进入文章内容；原稿中的摄影署名保留。
标题和图片 URL 的处理由同一个 `publication.js` 提供，预览与导出不各自维护规则。

## 验证边界

本机可用的 Homebrew Ruby 为 4.0.7；仓库 `.ruby-version` 指定 4.0.6，
该精确版本尚未复验。未修改 Ruby 设置或原有 Makefile。

本地 contenteditable 粘贴不能模拟微信的清洗与图片转存规则。公众号后台粘贴、
草稿保存回显、站外链接保留及微信 iOS/Android 的实际字体和段距仍需人工验收。
没有接入公众号 API、上传草稿或发布。文章与图片原件保持不动，已有原文编辑保留。
